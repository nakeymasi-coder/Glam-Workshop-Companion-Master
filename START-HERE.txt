GLAM WORKSHOP COMPANION MASTER TEMPLATE

You only need to edit: js/workshop-settings.js

1. Duplicate this entire folder for a new workshop.
2. Open js/workshop-settings.js in VS Code.
3. Change the workshop title, cards, sessions, lessons, prompts, resources, replay links, help answers, and completion wording.
4. Keep quotation marks and commas in place.
5. Open index.html with Live Server to test it.

IMPORTANT
- Give every session and lesson a unique id using lowercase words and hyphens.
- Change storageKey for every new workshop so student progress does not mix between companions.
- Replace every # resource or replay link before delivery.
- Do not edit app.js unless you are changing how the companion works.
